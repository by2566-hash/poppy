## 4. Drift metric: cleared context + embedding + judge

**What is measured.** Two drifts, both needed, with different target directions:
- **Round-trip drift** (Ryan's example): asked question → output → inferred question. Target: small. Measures "does this option answer the question asked" (criterion 1) without a gold plan.
- **Knob drift**: the same question under two knobs (phrasing, k, profile, plan check, model). Target depends on the knob: paraphrases should move little; options inside one run are supposed to differ.

**Pipeline per option (stripped condition).**
1. **Inference, context cleared:** a fresh sandbox, read-only, nothing from the run but `values.csv` (no chart, no title, no answer, no question). The model returns a structured guess `{question, metric, denominator, grouping, population, time_window, filters}`. Model: not the generator of the run; Luna in a fresh context is the fallback (FOLLOWUPS §3 decision 4). The chart-only condition is run once as the leaky ceiling and never used for decisions.
2. **Embedding distance:** a local sentence-embedding model; cosine distance between the asked question and the inferred question. Reported as a **ratio to the repeat floor** = the distance among inferred questions from repeat runs of the same asked question (P9).
3. **Judge:** sees the asked question and the structured guess (not the chart, not the answer, not the embedding score). Returns one class and one quoted field:
   - `aligned`: answers the asked question under a reasonable reading (for ambiguous questions, any legitimate reading of "safer" or "dangerous" is aligned);
   - `substituted`: answers a neighbouring question (a different denominator, population, filter or window) — the I1 per-crash option, the A1 Brooklyn-assigned-records option;
   - `unrelated`.
   Plus `mismatch_field` ∈ {metric, denominator, population, filters, time_window, none}.

**Boundary of the judge (what it does and does not do).**

| The judge does | The judge does not |
|---|---|
| classify alignment of the inferred plan with the asked question | judge correctness of numbers (g8 `gold_match`, provenance) |
| name the one field that differs and quote it | judge disclosure or framing quality (g8 trap items) |
| break the cases embedding cannot: near-identical wording, different meaning (per-mile vs per-crash) | see the chart, title, answer or run folder |
| provide the labels against which the embedding metric is validated | see the embedding score (keeps the two independent) |
| run twice; disagreements go to the human label set, as with g8 | decide alone: the loop's keep rule uses its class *and* g8 |

**Validation before use (Bo's probe, ≈ 1 h for the embedding part).** Pairs already on disk: positives = original ↔ casual ↔ formal (F2, 6 bases × 3); hard negatives = neighbouring questions written by hand (I1 per-mile ↔ per-crash; A1 Brooklyn ↔ Brooklyn-assigned records; A2 crashes per hour ↔ casualty share; K2 total per weekday ↔ mean per calendar date); easy negatives = cross-base pairs. Acceptance: the embedding orders paraphrase < neighbour < unrelated (AUC per contrast, reported); if it fails on the hard negatives, the judge class is the only alignment measure and embedding is kept as a diagnostic. The judge is validated on the 30–40 hand-labelled options of the F3 design (decision 5) — the labels are Bo's, outside this document.

**Goodhart and what cleared context does.** Clearing the context protects the *measurement*: the inferring model cannot recover the question from memory. It does not protect the *optimisation*: a generator can still close the round-trip distance by restating the question in the title or the answer. Three guards, all needed: (i) the stripped input (title and answer are not shown, so restating them does not help); (ii) the generator never sees the drift metric or the inferred questions; (iii) the keep rule requires g8 silent-error not to rise, so a change that games alignment but breaks disclosure is reverted. The held-out P1–P10 run at the end is the fourth guard.

**Closed loop (what we report to Ryan).** Per iteration: silent-error (g8) before/after; stripped alignment rate (judge) before/after; round-trip distance ratio before/after; top-facet flip rate before/after; the arrows table. One knob, one paired re-run, a written keep/revert.
