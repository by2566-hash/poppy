# E010 scenario research (2026-11-08)

Scope: only the E010 failure. A data profile was in context, the agent did not act on it, and the profile replaced the agent's own NULL checks.

Method: one research subagent, web search plus primary sources. "V" means read in the primary source. "S" means from an abstract or search snippet only. Items marked "inference" are reasoning, not a source.

## Same failure elsewhere

**Knowing but not doing**
- Schmied et al. 2025: correct rationales in 87% of cases, yet 58% of actions stayed greedy (bandits). V. https://arxiv.org/html/2504.16078v1
- Anthropic, CoT faithfulness: a hint the model used is mentioned only 25% (Claude 3.7 Sonnet) / 39% (DeepSeek R1) of the time. Using a fact and disclosing it are separate behaviours. V. https://arxiv.org/html/2505.05410v1

**No lexical link between question and fact**
- NoLiMa (ICML 2025): when the needed fact shares no wording with the question, most models fall below 50% of their short-context score. S. https://arxiv.org/html/2502.05167v3
- Inference: "borough NULL 30%" shares no wording with `borough='BROOKLYN'`.

**Supplied context crowding out exploration**
- No direct study found. Our observation (NULL queries 1.0 → 0.1 per run) looks new.
- Nearest result, Wu et al., ACL Findings 2025: fuller context cut tool calls by up to 70%, framed as efficiency. V. https://aclanthology.org/2025.findings-acl.1149.pdf
- AGENTS.md study 2026: instructions were followed; descriptive overviews did not help. V (abstract). https://arxiv.org/abs/2602.11988

**Data agents and missing values / silent filters**
- KAMI ("How Do LLMs Fail in Agentic Scenarios?"): filters guessed without sampling the data; wrong zeros never validated. V. https://arxiv.org/html/2512.07497
- Gu et al., CHI 2024: the AI noticed bad rows but did not drop them; the authors recommend it consistently communicate its assumptions. V. https://arxiv.org/html/2309.10947v1
- BLADE: agents that explored the data covered more of the expert analysis decisions. V. https://arxiv.org/html/2408.09667v3
- AT&T, Shkapenyuk et al. 2025 (BIRD #1): NULL semantics enforced in code (a missing `NOT NULL` is flagged, up to 3 correction retries); the profile helped only after it was summarised per field and linked to the schema. V. https://arxiv.org/abs/2505.19988

## Intervention families → our candidates

| Family | Evidence | Downside | Our candidate |
|---|---|---|---|
| Action-tied rule + required slot | KAMI: an explicit missing-data rule took 52.9% → 87.5% (V). OpenAI GPT-4.1 guide: one firm sentence usually suffices (V) | self-report can be unfaithful; goodharting ("none") | **C1** `v2-cov` (slot in `interpretation`, share computed by code, checked in self-review); **C2** = C1 + profile |
| Just-in-time facts in the tool response | Anthropic, context engineering / writing tools (V, no numbers); Self-Debug with execution feedback +2–9% (V) | more text in tool output; pandas paths not covered | **C3** `jit` (notes on the agent's DuckDB queries); **C4** = C1 + C3 |
| Harness-detected, targeted revision | Tyen et al.: given the error location, accuracy +18–44 points (V); AT&T check-and-retry (V) | detection rules per failure type | not run this round (needs a second call per run); candidate if C1–C4 leave disclosure failures |
| Placement / quote-first | Anthropic: query last gives up to +30% on 20k+ token inputs (V); our prompt is about 3–8k tokens | small effect at our length | not run (low fit) |
| Self-critique alone | intrinsic self-correction hurt GPT-4 on GSM8K (V) | misses its own errors | D v2 already has one self-review; not a new arm |

Faithfulness guard (from the evidence): a declared exclusion is a self-report. After the runs we check it against the code, i.e. compare the stated share with the share the agent's filter really drops (A1: NULL-borough share 2013–2025).
